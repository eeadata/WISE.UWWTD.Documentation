# Private dataset

The private dataset holds the reporting contact details. It contains personal data, so it is kept
separate from the data that is published.

According to the draft, it is available only on a need-to-know basis to users with access to the
Member State's dataflow, a limited number of external consultants, EEA staff working with the
dataflow and DG ENV staff. See the Reportnet 3 privacy policy.
