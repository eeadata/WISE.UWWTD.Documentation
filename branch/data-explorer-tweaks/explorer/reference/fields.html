Field tables

The fields of every table of the rUWWTD dataflows, as in the documentation, which reads the same files. Select a table, or search the fields of all of them. Drafts: names, types and statuses may change.

Template databases

An empty database of each dataflow, made from the same files, to load data into and check it against the keys, the required fields and the code lists:

Each has the reporting tables with their keys and required fields, constraints from the types (such as lengths, dates and values of 0 or more), the code lists filled in tables cl_<Type> with foreign keys to them, a Metadata table of the tables and fields in the layout of the Water Framework Directive documentation, and an _about table. Foreign keys are only checked when enabled on each connection, with PRAGMA foreign_keys = ON. Conditions ("Required if ...") are not enforced: they are in Metadata.condition, and are left to the quality checks. Drafts, like the documentation.

The files are the CSV sources of the field tables in the repository (reference/schema); its README explains the columns. Definitions and conditions may contain documentation markup, such as {ref}`label`, which is shown here as a link.
